The final lifespan() should look like:
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    settings = get_settings()
    LOGGER.info("vdr-agent starting env=%s log_level=%s", settings.env, settings.log_level)

    executor = ThreadPoolExecutor(max_workers=50, thread_name_prefix="bedrock")
    loop = asyncio.get_event_loop()
    loop.set_default_executor(executor)
    LOGGER.info("ThreadPoolExecutor configured: max_workers=50 thread_name_prefix=bedrock")

    await DatabasePool.initialize(
        host=settings.db_host,
        port=settings.db_port,
        database=settings.db_name,
        user=settings.db_user,
        password=settings.db_password,
        min_size=2,
        max_size=10,
    )

    yield

    await DatabasePool.close()
    LOGGER.info("vdr-agent shutdown complete")
```

WHY 50 workers: GlobalRateLimiter caps concurrent Bedrock calls at 10, but Python's default thread pool is `min(32, os.cpu_count() + 4)` — typically 8–12 workers. With 10 concurrent asyncio.to_thread() calls, requests would queue. 50 workers gives headroom for Bedrock calls plus other asyncio.to_thread() usage. This directly prevents the deadlock pattern documented in ingestion-service TEMP-007.

Do NOT change any other part of the file.
